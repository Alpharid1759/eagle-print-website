# Eaglez Prints Abuja — Website

Marketing site for **Eaglez Prints Abuja**, a printing & branding shop at Murg Plaza, Area 10, opposite UTC, Garki, Abuja.

Built with Next.js (App Router), TypeScript and Tailwind CSS v4.

## Develop

```powershell
npm install
npm run dev
```

## Deploy

Import the repo on [Vercel](https://vercel.com/new) — framework is auto-detected as Next.js, no env vars required.

Business details (phone, hours, services) live in `lib/site.ts`.
